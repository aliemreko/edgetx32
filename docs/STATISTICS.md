# Statistics — EdgeTX32 vs upstream EdgeTX

Generated by `tools/esp32/compare_sim.py` (host simulations + static analysis).
**Not** on-radio wall-clock MHz measurements — same PC runs both sides so equal
ops/s means **algorithmic parity**. Dual-core / jitter rows model architecture.

Re-run:

```bash
export EDGETX_UPSTREAM=/path/to/edgetx   # optional; auto-clones if missing
python tools/esp32/compare_sim.py
python tools/esp32/generate_compare_pdf.py
```

## Mixer simulation headroom @ 250 Hz

Python model of expo + mixes (+ curves / logical switches on heavier profiles).
Headroom = simulated ticks per second ÷ 250.

| Profile | Upstream | EdgeTX32 |
|--|--|--|
| Light (16 ch / 32 mix) | ~420× | ~430× |
| Medium (32 ch / 64 mix + curves) | ~99× | ~100× |
| Heavy (+ 32 logical switches) | ~89× | ~88× |

Both stay far above the real-time floor (1×). Numbers track each other because
the portable mixer math is the same.

## Theoretical platform comparison

| Metric | TX15-class STM32H750 | ESP32-S3 |
|--|--|--|
| CPU | Cortex-M7 ~400–480 MHz | Dual LX7 up to 240 MHz |
| UI memory | SDRAM | PSRAM (e.g. 8 MB) |
| Mixer determinism | Mature NVIC + timer | gptimer + core-1 pin |
| Connectivity | Optional BT | Wi‑Fi + BLE integrated |
| DIY availability | Full radio BOM | DevKit + UART module |
